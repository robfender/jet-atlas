ASSET DISPLAY AND THEMES
Native masks/colours are deterministically rendered from source figures with isotropic pixel geometry. Original black display background is converted to alpha: V=max(R,G,B), alpha=V, RGB'=255*RGB/V; valuesV<5 transparent. This reproduces the original image on black to rounding precision and permits a light theme without opaque black rectangles. Light mode attenuates emissionRGB and boosts faint alpha for legibility. Colours and display intensity are illustrative, not flux-calibrated comparisons. Display width is isotropically scaled along with length; apparent width is not an intrinsic-width deprojection.

PHYSICAL SIZE MODE - 18 November 2026
Each source converts R_G per pixel to parsecs per pixel using its own mass and GM_sun/c^2 =4.785560552051379e-14pc. This recovers the original angular or printed physical-bar calibration. Projection remains independent; no additional mass-normalisation or arbitrary scaling. Sources below one plot pixel are labelled core-position markers, not resolved emission. Inset magnifications and physical pc/kpc/AU bars are explicit; physical mode starts without insets.
