How to read this comparison +

Each radio nucleus is placed on the dotted core line. The images are rotated so their principal outflow axes run vertically; north is not necessarily upward. In the deprojected view, distances use the adopted inclination for each source. M87’s halo, NGC 6251’s outer lobes, Cen A’s outer lobes and Alcyoneus stay projected because their viewing angles are not securely established. The inner-jet angle does not fix the geometry of outer lobes. For 1E 1740.7−2942 and GRS 1758−258, the adopted inclinations are 55° and 61°, respectively, from X-ray disc reflection; both deprojections assume disc–jet alignment.

The size switch changes the calibration of each image using its own black-hole mass: physical length = (length in RG) × GM/c². Physical distances use parsecs (1 pc ≈ 206,265 AU). Switching units fits the selected sources and starts with enlarged insets off in the physical view. Sources smaller than a pixel are indicated by labelled core markers, not artificially enlarged emission. Optional insets carry their own magnification and scale.

The ruler uses RG = GM/c², not the Schwarzschild radius 2RG. Masses, distances and inclinations are fixed to the documented values below. Displayed widths use the same image magnification as lengths; this is an illustrative image comparison, not a reconstruction of intrinsic transverse jet widths.

These observations trace different components: compact jets, knots, inner lobes and a radio halo. Their detected endpoints depend on sensitivity. The Eddington ratios are approximate radiative Lbol/LEdd, not jet efficiencies; J1727’s value refers to the peak hard state, not its imaging epoch.
